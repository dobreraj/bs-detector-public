# BS Detector Privacy Policy

This folder contains a standalone privacy policy page for `BS Detector`.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html` from this folder.
3. In the repository settings, enable GitHub Pages from the `main` branch root.
4. Use the generated Pages URL in App Store Connect as the Privacy Policy URL.

Before publishing, update the contact section in `index.html` if you want to include an email address or website.
